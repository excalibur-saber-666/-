一、问题重述
1.1 问题背景
我国地域辽阔，自然条件复杂，因此灾害性天气种类繁多，地区差异大。其中，雷雨
大风、冰雹、龙卷、短时强降水等强对流天气是造成经济损失、危害生命安全最严重的一
类灾害性天气[1]。以2022年为例，我国强对流天气引发风雹灾害造成的死亡失踪人数和直
接经济损失分别占73%和69%。由于强对流天气具有突发性和局地性强、生命史短、灾害
重等特点，其短时（0~12小时）和临近（0~2小时）预报通常也是天气预报业务中的难点[2]。
传统强对流天气临近预报主要依靠雷达等观测资料，结合风暴识别、追踪技术进行雷
达外推预报，即通过外推的方法得到未来时刻的雷达反射率因子，并进一步使用雷达反射
率因子和降水之间的经验性关系（即 Z-R 关系）估计未来时刻的降水量[3]。近年来，随着
大数据的积累和计算机算力的发展，人工智能及深度学习技术发展迅速。深度学习方法是
一类数据驱动的方法，理论上其性能随着训练数据量增大而提升，因此很适合有大量雷达
观测数据积累的短临预报领域。目前国际上主要有两类基于深度学习的短临预报模型，一
类基于卷积神经网络（Convolutional Neural Networks, CNNs），如U-Net 等模型[4]；另一
类基于循环神经网络（Recurrent Neural Networks, RNNs），如ConvLSTM、DGMR 等模型
[5]。
雨滴在降落过程中受到空气阻力作用，形状可呈扁球形或馒头形，并且一般来说越大
的雨滴越扁。因此，雨滴对水平偏振（电场振动方向在水平面内）的电磁波和垂直偏振（电
场振动方向在垂直平面内）的电磁波的反射特征是不一样的[6]。传统雷达仅能发射和接收
一个偏振方向上的电磁波，而新型的双偏振雷达可同时发射和接收在水平和垂直两个偏振
方向的电磁波，可以根据两个偏振方向上的回波的强度差别、相位关系等信息获得降水粒
子的大小、相态、含水量等信息[7]，这些信息被统称为微物理信息。近年来研究表明，双
偏振雷达变量反映的微物理信息里包含了对流系统的演变状态、空间动力结构等关键信息
[8]。因此，双偏振雷达变量的应用，理论上对于强对流预报有重要意义。

5.2 模糊效应问题与可行性分析
5.2.1模糊效应
模糊效应是一种心理学上的描述性的研究，也是决策研究中必要的一环。简单来说，
人脑在进行决策判断和选择时，并不太擅长进行绝对判断，当一个“平均的”结果呈现在面
前时，人们往往无法从中提取出有效的信息。比如说在锚定效应的研究中，在对自己完全
不了解的领域进行估计时，大脑会围着轮盘上随机转出来的无意义数字打转，死活都要找
一个参照点。所以比起有明确概率的选项，无明确概率的选项显得风险很大而期望收益不
高。模糊效应，是一种认知偏误。决策由于缺少信息或者是模糊而受到影响。这个效应显
示，对于有利的结果，人们倾向于选择概率是确定的那一个。
而在降雨临近预估中，造成思维偏误的原因是关于降雨未来信息的不足（即问题一中
的神经网络只能获得雷达 Z 观测量），而你认为你有足够的关于降雨预报的信息（即信息
H
量很大）（实际上并没有，因为只有单一信息）。基于充足信息做出的决策让你更有信心，
但更有信心不代表这是更好的选择。比如虽然整体上某片区域我预测的同极化回波开始升
高，但你并没有在意这片区域的其他参数是否发生了变化（如：非降雨因素造成的衰减、
交叉极化散射回波异常等等）。该区域在未来可能也并不是可以预估大概率下雨，而是同
样无法确定。
因此，对于模糊效应，通常存在几种产生原因，如下图：

① 数据精度限制：
在雷达降水预报中，观测数据的精度对于预报结果的准确性至关重要。然而，受限于
雷达设备的分辨率、噪声干扰、仪器校准等问题，观测数据的精度存在一定的局限性。此
外，降雨过程中的复杂气象条件可能会导致数据的不连续性和不稳定性，进而影响到预报
结果的可靠性和真实性。
② 数据处理算法局限性：
雷达回波数据处理算法是获取降雨信息的关键步骤。然而，常用的雷达数据处理算法
在面对复杂气象环境和不同类型降水（如小尺度降水、雪、冰雹等）时，可能存在着一定
的局限性。例如，当前一些数据驱动的算法在进行强对流预报时，倾向于生成接近于平均
值的预报，即存在“回归到平均（Regression to the mean）”问题，因此预报总是趋于模糊。
此外，传统的经验关系和统计模型在描述不同类型降水的特征时可能存在误差，不能完全

准确地提取降雨粒子的大小、相态和含水量等信息。
③ 大气环境复杂性：
大气环境的复杂性是导致降雨预报模糊效应的另一个重要原因。大气中的湍流、气溶
胶、颗粒物和尘埃等都会对雷达波束的传播路径和散射特征产生影响，从而使得观测数据
受到一定的扰动和干扰。此外，大气中存在的悬浮物质和水变形导致回波信号的复杂形态，
进而造成降雨预报结果的模糊性。
5.2.2可行性分析
为了缓解判断的模糊效应，一般有三种方法：
① 发现影响判断的模糊概率
应对任何问题的第一步都是识别问题。模糊效应的问题是大脑的系统造成的，基于同
样的原因大脑会合理化你的选择，给出一个看上去非常合理的解释，回避掉你不想承认的
真实原因。
② 调整评估手段
一件事件的结果及其效用有很多角度，在一个角度下因为信息缺失而算不清概率的
事，在另外一种评估角度下可能就是清晰的。
③ 补足信息
为了使信息逐渐明确并缓解模糊效应，我们可以采取一些措施来补足信息并提高回答
的准确性。首先，需要提供更多细节和背景信息。其次，需要基于引用可靠的来源和数据
支撑对数据进行分析。在此过程中逐渐明确信息，并最终实现消除模糊效应的目标。使信
息逐渐明确。
在几种措施中，第一种模糊概率影响因子复杂，难以定量评估并使用。因此，在降雨
临近预报中为了缓解上述的预报的模糊效应，使预报出的雷达回波细节更充分、更真实，
本题目主要采取②, ③措施。
调整评估手段：在本文中，神经网络就相当于那个产生了“模糊”的大脑，为了使神经

5.5 本章小结
题目要求优化第一问中建立的模型，通过降低“模糊效应”，提高雷达回波细节，使其
更充分，更充实。本文在调研了什么事“模糊效应”以及模糊效应的缓解方法后，选择了输
入-输出双层拓展的 NARX-RNN模型。
首先，我们在扩展细化了输入层数据，加入了空间变化参量空间梯度、气象变化参量
雷达强点、雷达变化参量雷达类型，进一步扩充了神经网络输入层细节，使得神经网络学
习训练更清晰、充分、全面。
然后，我们扩展补充了输出层数据，从雷达细节参数优化和气象微物理参数补充两个
方面进行。在雷达参数方面，我们最终形成了双极化四输出完备双雷达数据集，包含双偏
振雷达两个极化方向上幅值相位信息。在气象参数补充方面，我们充分的调研了雷达参数
在反演气象微物理参数的物理机理，并基于机理生成了包含气象类型、降水粒子尺寸、含
水量的气象微物理参数集。结果表明，该网络可以实现对未来雷达参数数据和气象微物理
参数数据的临近预报。并且，由于输入层的优化，该网络生成的已知雷达参数相比于测量
真值更加精确可信，以分数均方差为例，样例性能提升 3%-59%不等。

七、问题四模型的建立、分析与求解
7.1 问题分析
问题四需要设计一种数学模型，使得可以对双偏振雷达参数在强对流降水预报中的贡
献进行定量表述和比较。然后，基于这一种评价方式，优化模型数据的融合策略，实现模
型对“突发性降雨类型”和“地域信息”降雨的泛化能力提升。因此，本文首先分别在考虑单
| 偏振信息（仅Z                           | ）和考虑双偏振信息（Z |     | 、Z 和K | ）的条件下，融合 |               | 2、3问的网络模 |     |
| --------------------------------- | ----------- | --- | ----- | -------- | ------------- | -------- | --- |
|                                   | H           |     | H DR  | DP       |               |          |     |
| 型，分别对未来时间降雨量进行临近预报。然后，基于熵权-TOPSIS |             |     |       |          | 方法，对相关系数(CC)、 |          |     |
均方根误差(RMSE)、相对偏置(RB)和分数均方差(FRMSE)四种网络系数进行权重赋值，得
到对预报结果的评估模型，评估双偏振雷达在强对流临近降雨预报中的贡献。最后，基于
仿真数据和随机森林，建立突发性降雨分类模型，对附件数据库进行分类标签。然后，在

八、模型的评价
8.1 模型的优点
（1）基于线性拟合和 RMSE 的LOF异常值检测模型，在时间帧和空间比较上分别搜
寻异常点，基于 LOF 方法对空间位置下的 RMSE 进行异常值分析筛除，最终获得清洗后
的“可信”数据集。
（2）输入挖掘-输出细化的双驱动去模糊化临近预报模型，进一步挖掘数据，扩充模
型输入，使网络模型输入更有条理，更有深度。同时，进一步挖掘双偏振雷达参数与参数
之间，参数与降雨微物理特性之间的物理机理，使模型预报的结果在雷达回波纬度和气象
微物理参数纬度两方面都更清晰，更细节。
（3）基于测算融合的 BP 神经网络降水量反演模型，基于降雨气象模型和降雨散射特
性模型，利用自研的复杂背景环境散射特性仿真软件，仿真生成不同降雨量下的气象散射
特性，形成不同降雨量下的 Z 、Z 仿真数据集，为测算融合提供了数据基础。
H DR
（4）评估模型建立与双偏振雷达贡献度评估中，通过优化数据融合的高泛化性网络
模型，在神经网络中输入层加入考虑不同位置、降雨突发与否，实现对突发性和局地性强
的强对流天气的预估。
8.2 模型的缺点
在建模的过程中，对问题进行了一定的条件简化，建模模型可能无法完全捕捉到所有
的系统变量和相互关系，导致预测的准确性受到一定限制，在实际的应用中具有一定的局
限性。
8.3 模型的推广
将降雨预测模型与其他应用和系统整合，提供实时、准确的降雨预测信息，以支持决
