1 问题重述
1.1 引言
随着社会经济的加速发展，在智能家居，物联网，自动驾驶等领域中，对于移动物体
的超分辨率需求越来越大。现有的移动定位产品通常为调频连续波雷达FMCW，通过发射
线性扫频波，利用回波信号进行定位。但现有产品通常使用简单的加窗 FFT 或 MUSIC 等
简单信号处理方法，分辨率低，抗噪声性能差，无法满足现有需求。事实上，整个雷达估
计问题可以视为一个二维线谱估计问题。在线谱估计领域，超分辨率类的算法主要分为超
分辨率子空间方法 [5, 6]，压缩感知类算法 [7, 8, 2] 与贝叶斯类算法 [1, 4]。本文通过对各
类算法的估计类型，估计性能，复杂度与抗噪性能进行对比，最终选择多维变分贝叶斯方
法最优的低复杂度高精度线谱估计方法。通过结合信息准则 [9] 模型阶数选择，数据关联，
后端处理与结构噪声估计[10,11]，可以适用于各类复杂场景。

1.2 问题的提出
整个问题的求解思路如图1.1所示。
问题一：问题一要求根据无噪声仿真数据建立定位模型计算物体位置。我们根据雷达
的接收信号模型在频域与角域的阵列响应特性建立了二维线谱估计定位模型，包含模型阶
数估计与二维频率估计。并从雷达分辨率与克拉美罗界的角度得到了估计问题的下界。对
于模型阶数估计，我们使用贝叶斯信息准则进行判决。超分辨率二维频率估计采用可达克
拉美罗界的四类算法：二维牛顿正交匹配跟踪，二维原子范数方法，多维变分贝叶斯线谱
估计方法与超快速线谱估计方法中选型。最终选择多维变分贝叶斯线谱估计MDVALSE方
法进行超分辨率求解。
问题二：问题二要求在高斯噪声环境下定位多个物体。我们选用能够估计噪声方差的
MDVALSE 方法结合贝叶斯信息准则进行多目标定位。
问题三：要求设计在线低复杂度算法实现移动超分辨率定位，通过MDVALSE方法结
合最近邻数据关联与卡尔曼滤波轨迹优化，实现了两物体轨迹的低复杂度高精度定位，并
分析了算法的理论复杂度与实际复杂度。
问题四：要求考虑天线阵列结构误差情景下的鲁棒定位问题。通过 MUSIC+fmincon
优化算法对天线结构误差进行自校正。校正后通过MDVALSE方法进行鲁棒估计。

4.3.1 数据关联算法
依据问题所提出的实际背景，假如待测物体之间的间距较为紧密，我们需要数据关联
算法进行目标追踪以保证之后物体运动轨迹分析的正确性。设在一个密集环境中（环境中
| 多个目标紧邻）对N |                                          | 个目标进行跟踪，该任务具有以下特征： |     |     |     |     |     |     |
| --------- | ---------------------------------------- | ------------------ | --- | --- | --- | --- | --- | --- |
|           | (1) 每一个传感器的观测结果以一定的时间间隔传输至融合节点；          |                    |     |     |     |     |     |     |
|           | (2) 传感器可能在特定的时间间隔内没有观测结果输出（目标处于盲区或噪声掩盖）； |                    |     |     |     |     |     |     |
(3)系统是因果的，因此对于任意目标，在每一个时间间隔内，不能预先获知传感器的
输出结果；
现在针对不同多目标运动目标检测场景有多种相应算法进行目标跟踪，包括近邻算
法，概率数据关联算法，多重假设检验，图形算法等。其中，近邻算法计算复杂低实时性
较好，但是难以分清较为接近或是交叉的轨迹。考虑到实际问题场景，我们选择近邻算法
30

作为数据关联算法以加强整体算法的实时性。此外，我们发现本问题中路径具有角度相反
性，可以根据该性质简单的实现较好的数据关联。如果实际中遇到复杂数据关联问题，则
