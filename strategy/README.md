# 方法论与写作经验库

本目录回答的不是“哪个算法最热门”，而是四个更重要的问题：

1. 新题的数学结构是什么；
2. 为什么选择某类模型；
3. 如何证明结果值得相信；
4. 如何把推理链写清楚。

## 阅读入口

- [建模方法论](MODELING_PLAYBOOK.md)：审题、拆题、抽象、模型选择与组合。
- [题型索引](PROBLEM_PATTERN_INDEX.md)：按问题结构查建模路线。
- [验证指南](VALIDATION_GUIDE.md)：为不同模型匹配证据。
- [可解释性指南](EXPLAINABILITY_GUIDE.md)：结构、参数、机理和工具解释。
- [写作指南](WRITING_GUIDE.md)：摘要、分析、公式、结果和语言规范。
- [比赛工作流](COMPETITION_WORKFLOW.md)：从审题到提交的执行与检查表。
- [可追溯案例](EVIDENCE_CASES.md)：只记录能够链接到原论文的实例。
- [方法索引](METHOD_INDEX.md)与[知识点索引](KNOWLEDGE_INDEX.md)：等待逐篇语义审阅后扩充。

## 证据等级

- **A：论文证据**——能够链接到具体论文正文，且表述不超出原文。
- **B：通用规范**——合理的建模或写作建议，但不声称是 145 篇论文的统计结论。
- **C：待审阅**——尚未逐篇确认，保留为空或 `unknown`。

历史论文只能说明“这种思路曾如何使用”，不能证明它对新题必然有效。新题仍须依据当前数据、约束和评价目标重新选择模型。
