# 题型与建模路线索引

> 下列流程是审题起点，不是固定模板。先判断输出、数据结构和约束，再删改步骤。

## 预测与回归

- 识别：输出为连续量、概率或未来轨迹。
- 先检查：时间顺序、对象分组、外推范围、目标泄漏和真值可靠性。
- 路线：探索结构 → 简单 baseline → 特征/机理 → 候选模型 → 合理划分 → 残差与泛化。
- 验证：MAE/RMSE 等需结合量纲；MAPE 与 R² 有适用边界。
- 常见错误：随机打乱时间、用测试集选特征、只报训练拟合。

## 分类与故障诊断

- 识别：输出为离散类别，可能存在类别不平衡或跨工况偏移。
- 先检查：类别定义、对象级分组、误判代价、标签噪声和域差异。
- 路线：数据质量 → 可解释特征 → 简单分类器 → 复杂模型 → 阈值与错误分析 → 必要时迁移。
- 验证：混淆矩阵、Precision、Recall、F1、ROC/PR-AUC、概率校准。
- 案例：[2025 E 轴承故障诊断](EVIDENCE_CASES.md#2025-e轴承故障诊断2025-e-003)。

## 聚类与分群

- 识别：没有可靠标签，需要发现结构或为后续模型分层。
- 先检查：距离定义、尺度、离群点、簇数是否有实际意义。
- 路线：标准化/特征 → 多种距离与算法 → 内部指标 → 稳定性 → 领域解释 → 下游用途。
- 常见错误：把聚类编号当客观类别、只以一个内部指标选模型。

## 综合评价与抽象概念量化

- 识别：舒适度、公平性、风险、美学或综合表现无法直接观测。
- 路线：概念定义 → 子维度 → 可观察指标 → 方向与尺度 → 权重/映射 → 综合量 → 敏感性。
- 先检查：指标是否代表概念、是否重复、权重来源是否可追溯。
- 验证：权重扰动、排名一致性、留一指标、不同赋权方法对照。
- 案例：[2025 F 园林美学量化](EVIDENCE_CASES.md#2025-f园林美学量化2025-f-004)。

## 优化决策与调度

- 识别：存在可控决策变量、目标和不可违反的约束。
- 路线：决策变量 → 目标 → 约束 → 数学性质 → 求解器/算法 → 可行性 → 基线 → 敏感性。
- 优先：线性、凸、规模适中时考虑成熟数学规划；非凸、离散或组合复杂时再选择启发式或分解方法。
- 验证：约束满足、目标改善、下界/基线、多个随机种子、计算预算。

## 多目标优化

- 识别：目标间存在真实冲突，而非同一方向的重复指标。
- 路线：尺度统一 → 冲突诊断 → 加权、ε-constraint、Pareto 或分层 → 权衡解释 → 偏好选择。
- 加权求和可用，但需说明目标可补偿性、权重来源和敏感性。
- 常见错误：只展示一个权重组合，并把该点称为全局最优。

## 路径规划与网络问题

- 识别：节点、边、连续空间、障碍、时变代价或动力学约束影响路线。
- 路线：空间/网络表示 → 代价函数 → 约束 → 候选算法 → 可行性 → 路径对比与扰动。
- Dijkstra/A* 适合相应图结构，但连续或动态问题可能需要采样规划、最优控制或滚动优化。

## 图像识别与空间重构

- 路线：成像质量/预处理 → 分割或检测 → 对象提取 → 几何参数 → 空间重构 → 风险或决策。
- 验证：像素与对象两级指标、拟合误差、几何一致性、下游误差传播。
- 案例：[2025 C 裂隙识别到三维重构](EVIDENCE_CASES.md#2025-c裂隙识别到三维重构2025-c-005)。

## 信号处理

- 先检查：采样率、频带、工况、窗长、同步和混叠。
- 路线：去噪/分段 → 时域 → 频域 → 时频域 → 机理特征 → 分类/预测 → 跨场景验证。
- 常见错误：先切窗后随机划分导致相邻片段泄漏；仅用高维谱图而不核对物理频率。

## 多源融合

- 路线：来源与可靠性 → 时间对齐 → 空间对齐 → 量纲统一 → 缺失与冲突处理 → 融合 → 融合前后对比。
- 先区分数据级、特征级和决策级融合，不要把简单拼接自动称为融合模型。

## 机理建模与参数估计

- 路线：领域规律 → 基本方程 → 简化假设 → 参数可辨识性 → 数值求解 → 实测对照 → 敏感性与外推边界。
- 机理模型拟合好不等于参数唯一；需要防止多个参数互相补偿。
- 案例：[2024 C 经典方程与温度修正](EVIDENCE_CASES.md#2024-c磁芯损耗模型c24102890089)。

## 不确定性、敏感性与鲁棒性

- 不确定性：输入、参数、模型结构和场景中哪些未知；
- 敏感性：哪些变化主导输出；
- 鲁棒性：扰动下方案是否仍可接受；
- 工具：置信区间、bootstrap、Monte Carlo、局部/全局敏感性、情景分析、鲁棒优化。

## 快速选择规则

不要问“这题能不能用 XGBoost”，先问：输出是什么、结构是什么、最简单可信 baseline 是什么、核心风险是什么、用什么证据才能支持结论。
