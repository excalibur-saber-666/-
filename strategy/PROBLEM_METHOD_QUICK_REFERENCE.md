# 不同题型方法论速查

> 本页依据用户提供的速查稿和 [24 篇跨年赛题样本](ANNUAL_QUESTION_EVIDENCE_MATRIX.md) 重新整理。它用于缩小候选路线，不是“题型 → 固定算法”的模板。表中方法是通用候选；具体论文证据以证据矩阵中的 source_md 为准。

## 30 秒识别顺序

1. 输出是类别、连续量、分组、排名、参数/状态、路径、排程，还是折中方案？
2. 数据是否具有时间、空间、网络、图像、信号或明确机理结构？
3. 是否存在可控变量、硬约束、多目标冲突或输入不确定性？
4. 训练场景与应用场景是否同分布？
5. 最简单、可复现、可解释的 baseline 是什么？
6. 哪个已经观察到的缺陷足以支持增加复杂度？

    输出对象
    → 数学任务
    → 数据与机理结构
    → baseline
    → 暴露的缺陷
    → 候选改进
    → 匹配的验证证据

## 二十类题型速查

| 题型 | 最小 baseline | 常见升级路线 | 最少验证证据 |
|---|---|---|---|
| 描述统计与影响因素 | 描述统计、散点、Pearson/Spearman | 检验、回归、PCA、模型重要性、空间统计 | 分布、效应量、多重检验、子样本稳定性；关联不写成因果 |
| 回归与连续量预测 | 均值、线性/岭回归、经典经验式 | 非线性回归、RF/XGBoost/SVR、机理加数据修正 | MAE/RMSE、残差、区间、分组或外部验证 |
| 时间序列预测 | last value、季节朴素、移动平均 | ARIMA/ETS、状态空间、树模型、LSTM/TCN | 前向/滚动验证、多跨度误差、残差自相关、区间覆盖 |
| 分类与故障诊断 | 多数类、规则、逻辑回归/浅树 | SVM、树集成、CNN/Transformer、代价敏感学习 | 对象级划分、混淆矩阵、F1/PR-AUC、校准、错误样本 |
| 聚类与分群 | K-means/层次聚类 | DBSCAN、GMM、谱聚类 | 多初始化、Silhouette/DBI/CH、重采样稳定性、领域解释 |
| 综合评价与排名 | 等权标准化加总 | AHP、熵权/CRITIC、TOPSIS、PCA/因子、模糊评价 | 指标代表性、冗余、权重扰动、留一指标、排名稳定性 |
| 组合优化与调度 | 现行规则、贪心、松弛或小规模精确解 | LP/MILP/CP/DP、局部搜索、GA/SA/PSO | 约束复核、目标值、上下界/基线、多种子、运行时间 |
| 多目标优化 | 单目标极值、固定权重解 | ε-constraint、目标规划、Pareto、NSGA-II | 前沿收敛/覆盖、偏好敏感性、可行性、折中解释 |
| 图论与路径物流 | Dijkstra、最小生成树、最近邻 | A*、网络流、TSP/VRP、采样/滚动规划 | 路径成本复算、连通/容量/时间窗、扰动、计算量 |
| 信号与时频分析 | 原始统计量、FFT、简单滤波 | STFT、小波、包络、EMD/VMD、DOA/参数估计 | 合成或参考信号、SNR 扫描、频率/定位误差、下游性能 |
| 图像识别与重构 | 阈值、边缘、形态学、连通域 | U-Net/DeepLab/YOLO、对象提取、几何拟合 | IoU/Dice/mAP、对象级误差、跨场景、下游误差传播 |
| 参数反演与逆问题 | 最小二乘/矩估计 | 非线性优化、稳健损失、贝叶斯反演、滤波 | 合成回收、可辨识性、区间、残差、初值敏感性、物理范围 |
| 机理与微分方程 | 经典方程、低阶近似 | ODE/PDE、状态空间、机理加残差学习 | 量纲、边初值、极限情况、参数辨识、实测对照 |
| 仿真与离散事件 | 手工小规模或简化解析模型 | 离散事件、Agent、Monte Carlo、系统动力学 | 代码核验、极端情形、重复运行、独立数据或替代表述 |
| 多源融合与同化 | 单源模型、简单加权/拼接 | Kalman/EKF/EnKF、贝叶斯、特征/决策融合、变分同化 | 单源对照、去源消融、对齐误差、冲突/缺失场景、校准 |
| 空间数据与 GIS | 最近邻、IDW、无空间项模型 | Kriging、空间回归、点过程、图/时空模型 | 坐标与尺度、空间分块验证、残差空间相关、分辨率敏感性 |
| 迁移学习与域适应 | 不迁移模型、简单校准 | 微调、CORAL/MMD、DANN、伪标签 | 目标域独立证据、无迁移基线、负迁移、不确定性 |
| 不确定性与鲁棒决策 | 单因素扰动、标称最优 | bootstrap/Monte Carlo、情景、鲁棒/随机优化、CVaR | 覆盖/收敛、样本外可行率、尾部风险、性能—保守度 |
| 情景分析与长期规划 | 基准趋势情景 | 驱动变量情景、系统动力学、优化与路径组合 | 情景依据、参数可解释性、目标差距、跨情景稳健性 |
| 纯数学与算法构造 | 小规模解析/穷举 | 定理、分解、动态规划、数值优化、近似算法 | 正确性证明、小规模对照、误差界、复杂度、规模扩展 |

## 复合题的五层流水线

    数据层：表格 / 图像 / 信号 / GIS / 多源数据
    ↓
    表征层：特征 / 指标 / 物理参数 / 状态
    ↓
    认知层：分类 / 回归 / 聚类 / 预测 / 反演
    ↓
    决策层：评价 / 排序 / 优化 / 路径 / 调度
    ↓
    可信层：对比 / 不确定性 / 鲁棒性 / 泛化 / 可解释性

每个箭头都写清输入、输出、单位、假设和误差传播。不能因为流程完整，就默认每个中间结果都准确。

## 模型升级的三级门槛

### Level 1：最简单可信模型

先建立可解释、可复现的 baseline，并检查数据和任务定义。

### Level 2：针对已观察到的缺陷改进

例如非线性、类别不平衡、时空依赖、目标冲突、噪声、域偏移或复杂约束。新增模块必须对应一个可展示的缺陷。

### Level 3：复杂模型

只有当 Level 2 仍不能解决关键困难，并且数据量、计算预算、验证和解释能力足够时才使用。复杂度本身不是创新。

## 七条现场红线

1. t-SNE/UMAP 只能辅助观察，不能单独证明域偏移、类别可分或迁移正确。
2. SMOTE、标准化、特征选择必须只在训练折内拟合，避免泄漏。
3. 小样本不自动意味着灰色预测或深度学习适合；结构假设和验证方式更重要。
4. NP-hard 不自动意味着必须使用遗传算法；先检查规模、特殊结构、数学规划与问题分解。
5. 仿真与理论使用同一假设时不是完全独立证据；还需代码核验、实测数据或替代表述。
6. SHAP、特征重要性和注意力反映模型依赖，不自动给出因果或物理机制。
7. 在第二个数据集运行一次不等于鲁棒；必须明确扰动类型、范围和可接受标准。

## 本次阅读支持的跨题型经验

- 2022 A、2023 A、2024 F 展示了“理论/机理模型 + 仿真或误差分析”的路线。
- 2022 B/C/D、2025 A 展示了“问题结构 + 领域启发式 + 优化算法”，同时都提醒启发式最优性边界。
- 2023 E/F、2024 B/E、2025 C/E 展示了从特征/对象到预测或决策的多层链条，也暴露了划分、泛化和解释风险。
- 2023 D、2024 D、2025 D 展示了长期情景、空间场与多源融合需要单独处理时空一致性和外推边界。
- 2024 C、2025 B 展示了用明确 baseline 和受控候选比较触发模型改进。
- 2025 F 展示了抽象概念必须先操作化，再做权重、评价和优化。
