# 模型可解释性指南

> 可解释性用于说明模型为什么得到当前结果、结论在什么条件下成立。解释工具提供的是关联证据，不能自动证明因果关系。

## 解释的五个层次

1. **结构解释**：用“输入 → 中间量 → 输出”说明每个模块的职责，以及删除模块后会失去什么能力。
2. **参数解释**：说明参数的单位、符号、量级、估计方法和现实含义；检查参数是否可辨识。
3. **机理解释**：用守恒、几何、动力学、工程边界或领域知识核对趋势与极限情况。
4. **统计解释**：报告效应方向、区间、不确定性、共线性和适用条件；相关关系不写成因果关系。
5. **工具解释**：在前四层不足时，用特征重要性、SHAP、PDP、LIME、注意力或敏感性分析补充局部/全局证据。

推荐顺序：**结构 → 机理 → 参数与统计 → 数据证据 → 工具解释**。

## 常用工具与适用边界

| 工具 | 适合回答 | 使用前检查 | 不能据此断言 |
|---|---|---|---|
| 特征重要性 | 模型主要依赖哪些输入 | 重要性的定义、共线性、置换方式 | 特征具有因果作用 |
| SHAP | 单样本或总体预测如何由特征贡献组成 | 背景样本、特征相关性、输出尺度 | SHAP 值就是物理贡献或因果效应 |
| PDP | 某特征变化时平均预测趋势如何 | 特征是否强相关、考察区间是否有数据 | 所有个体都遵循平均趋势 |
| LIME | 某个样本邻域内黑箱的局部近似 | 邻域和扰动分布是否合理、重复运行是否稳定 | 局部线性解释代表全局规律 |
| 注意力权重 | 模型在内部计算中关注哪些位置/时刻 | 权重归一化、替代解释、扰动测试 | 注意力天然等于重要性或因果解释 |
| 敏感性分析 | 输入/参数扰动如何影响输出 | 扰动范围、分布、交互项、局部或全局方法 | 未测试范围内仍然稳定 |

## 不同模型的解释路线

- **机理模型**：方程来源 → 假设 → 参数含义 → 量纲与边界 → 实测对照。
- **统计模型**：变量定义 → 系数/效应方向 → 区间与显著性 → 残差与共线性 → 外推边界。
- **树模型**：全局置换重要性 → PDP/ICE → 个体 SHAP → 相关特征与泄漏审查。
- **深度模型**：输入表示 → 中间模块职责 → 消融 → 注意力/显著图 → 扰动与反事实检查。
- **优化模型**：决策变量 → 约束活跃性 → 目标权衡 → 影子价格/敏感性 → 情景变化。

## 最小可信解释

至少回答四问：模型依赖什么信息；这种依赖是否符合机理或数据；结论对扰动是否稳定；解释覆盖的是单样本、当前数据还是可推广场景。

## 常见误区

- 画一张 SHAP 图就宣布模型“完全可解释”；
- 把相关性、特征贡献或注意力写成因果机制；
- 只解释预测正确的样本，不分析错误和边界样本；
- 对强相关特征逐个解释，却不说明贡献可能在特征间重新分配；
- 解释图没有单位、样本范围、基准值或置信信息。

## 写作模板

> 模型结构上由……、……和……组成，分别负责……。在当前验证集与背景样本下，……工具显示模型主要依赖……；该趋势与……机理一致。对……进行 ±……% 扰动后，输出变化为……。这些结果支持模型在当前数据范围内具有一定可解释性，但不构成因果证明，且对……场景仍需独立验证。
