# 模型可解释性指南

> 本文是通用规范。可解释性应服务于题目和决策，不等同于生成一张 SHAP 图。

## 四个层次

### 1. 结构解释

明确输入、每个中间量和最终输出的关系。读者应能回答：某模块解决了哪个困难，其输出如何进入下一步。

### 2. 参数解释

说明参数的物理、统计或业务含义、单位、取值范围和来源。无明确含义的超参数也要说明调节方式与验证集隔离。

### 3. 机理解释

检查模型方向、边界和趋势是否符合领域规律。相关性或特征重要性不能自动升级为因果解释。

### 4. 工具解释

按需要使用特征重要性、PDP、SHAP、LIME、注意力或敏感性分析。工具只能解释指定模型在指定数据上的行为，不能替代结构和机理说明。

## 推荐顺序

```text
结构解释
→ 参数与单位
→ 机理一致性
→ 数据和误差证据
→ 必要时使用解释工具
```

## 常见误区

- 将相关性写成因果关系；
- 把某模型中的特征重要性当成变量客观重要性；
- 只展示局部解释，不说明样本代表性；
- 解释图没有基线、方向和量纲；
- 使用复杂模型后仅以“精度更高”为由跳过机理审查。

## 写作模板

> 在当前训练数据和模型设定下，变量 X 对预测贡献较高；结合……机理，其影响方向具有合理性。该结果反映模型关联而非因果效应，仍需独立数据或实验设计进一步验证。
